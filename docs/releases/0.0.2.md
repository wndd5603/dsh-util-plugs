# dsh-util-plugs 0.0.2

第二个稳定版本（日期包 `2026.11.17-1`，Release tag `0.0.2`）。

## 包
- 包名：`dsh-util-plugs`
- 日期包版本：`2026.11.17-1`
- 结构：1 bundle + 11 rows + 3 client halves，0 npm 依赖
- Release commit：`master`（tag `0.0.2`）

## 安装
```sh
dsh plugin --profile <profile> add github:wndd5603/dsh-util-plugs#0.0.2
```

## 包含能力
- 上下文哨兵（context-sentinel）
- 跨会话消息总线（message-bus）：投递状态、notFoundPolicy、maxBodyChars、strictMode、autoResume、队列/审计分页、协作网络
- 公告栏/任务板（bulletin-board）：属主/CAS、状态机、搜索/分页、全量 overview 计数
- 智能体公寓（agent-apartment）：agent home/团队/租约/经验、迁移/备份/恢复与重启写闸
- 持久记忆（agent-memory）
- 团队总线（team-bus）：会话网络、会议权限/CAS、跨进程 sidecar 锁、协作技能
- Agent 工作流（agent-workflows）
- 工作台状态（workbench-bundle）
- 自动备份（auto-backup）
- 安全宿主重启（host-relaunch）：插件控制台可配置 `allowRealRestart`
- 插件控制台（plugin-console）

## 破坏性变更
- `notFoundPolicy` 默认 `reject`；旧行为用 `queueUndeliverable:true` 或 `notFoundPolicy:'queue'`
- `allowPurge` 默认 `false`
- Web 已读回执改为只读
- `meetingDetail` 默认分页，UI 提供“加载更多”

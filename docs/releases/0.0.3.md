# dsh-util-plugs 0.0.3

## 重点

- **DSH-native team 为准**：退役 `team_init`、`apartment_team_*`、`apartment_task_role_*` 等插件 team 设计；历史数据保留只读。
- **保留全局能力**：全局任务板、会议、别名注册、租约、Agent homes/backup。
- **plugin-console 恢复**：作为当前自制设置界面，支持插件卡片与实时配置表单；DSH 原生 row config 待官方完善后再接。
- **召回**：`collaboration_recall` 只返回身份、别名、全局任务、租约、记忆键、artifact；不返回 team 字段和记忆正文。
- **安全**：Web 消息删除默认关闭（`webUi.allowDelete=false`），operator 显式开启；Web 记忆 reveal 逐条确认并审计。

## 说明

- 原生 `plugins.row.config` namespace 约定尚未适配；当前使用 plugin-console。
